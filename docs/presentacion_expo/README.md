# Presentación para la Expo Ciencia

Cuatro diapositivas para presentar el asistente en la Expo Ciencia, pensadas para
autoridades y estudiantes de secundario. Cada una tiene notas del orador.

1. Portada: qué es, proyecto IDI, integrantes y UNLP.
2. ¿Para qué sirve?: escucha, detecta el riesgo y guía, con una conversación real.
3. ¿Por qué no alcanza con un chatbot?: examen a libro cerrado (LLM solo) contra
   examen a libro abierto (RAG).
4. ¿Cómo funciona por dentro?: oído, alerta, memoria, cerebro y voz, con las
   mediciones reales.

La versión editable está publicada como Artifact de Claude (tipo Slides):
https://claude.ai/artifact/WVPUdfsJBHNzmW8f5zgMAa

Desde esa página se edita en el navegador, se presenta y se descarga en PDF o
PowerPoint. Es privada: para que otra persona la abra hay que compartirla desde el
menú Compartir.

## Archivos

Copia de la fuente de la presentación al 23/09/2026:

- `project/deck.json`: título, orden de las diapositivas, secciones y tipografías
  (Rubik y Nunito Sans, de Google Fonts).
- `project/slides/<id>.html`: una diapositiva por archivo, en un lienzo de
  1920×1080. Las notas del orador están en el `<aside>` del final.

Si se edita la presentación en la página, esta copia queda desactualizada. Para
modificarla con Claude, pedirle que parta de estos archivos o del link de arriba.
